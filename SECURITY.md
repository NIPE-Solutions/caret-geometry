# Security policy

Security fixes are provided for the latest stable major version. Report
vulnerabilities privately through GitHub Security Advisories for this
repository; do not open a public issue for an undisclosed vulnerability.

Use synthetic text in reproductions. Never include passwords, access tokens,
private messages, customer data, or real form contents.

Caret Geometry performs no network requests or telemetry. See
[`docs/security-and-privacy.md`](docs/security-and-privacy.md) for the
data-handling model.
