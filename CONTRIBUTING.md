# Contributing

Install with `npm ci`, then run `npm run check` and `npm run test:browser`. Geometry changes must include a real-browser regression that fails before the fix and passes in Chromium, Firefox, and WebKit.

Use only synthetic text in issues and fixtures. Never submit passwords, tokens, private messages, customer content, or other sensitive field values. Browser-specific workarounds must be documented in `docs/browser-notes.md` with an associated test and removal criterion.
